# 塑形连续性与录像对照 · 2026-10-28

本轮继续校准鼠标塑形、湿泥外观和 Chrome 帧耗时。基线是 `7ce785b`，本轮实际验证的生产入口为 `workshop-DbXPQJWh.js`。工坊继续使用普通鼠标光标，不显示玩家手部。

## 从录像测量到实际画面

原始文件为用户提供的 `屏幕录制 2026-10-26 193953.mp4`，1222×688、30 fps、17.7 秒；SHA-256 为 `E095FED124F72AC613FEB75AF52DA5C61BF200D1DD922C7D67B7DB52A3D48EC2`。没有改写原文件。

在 1.3–2.1 秒的可见横向拖动段，跟踪鼠标图案与器腹轮廓，在图像 441–449 行取半宽中位数。25 个有效样本的线性拟合得到 **半径像素变化 / 鼠标像素位移 = 0.15619**，拟合 RMSE 为 1.32 像素。方法和所有采样值见 [源录像测量](../qa/sculpt-reference-analysis.json)，脚本为 `scripts/analyze-sculpt-reference.py`。

归一化径向响应使用接触点的相机深度换算米/像素。独立的截图检查直接测量渲染结果：鼠标移动 188 px，器腹半径增加 30 px，增益与源录像拟合值相差 **0.00338**。截图检查允许约 2 px 边缘不确定性，颜色分割只针对这组 1920×1080 湿泥样本，不能当成所有背景通用的分割器。见 [截图轮廓报告](../qa/sculpt-r50-pixels.json)。

旧版从 Git 归档独立启动，相同资产、相同 JSON 起始坯体、相同真实鼠标动作；新版使用生产构建，旧版使用 Vite 开发服务。因此上述对照用于输入响应，不把两种构建方式的帧率当作严格性能对比。基线报告为 [sculpt-baseline-7ce.json](../qa/sculpt-baseline-7ce.json)。

录屏中的播放器显示过 `0:00 / 0:51`，原始输入事件与播放速率不可得。横向可见增益可以量化；高度增益 0.55、12 ms 响应时间常数属于当前交互校准，不能声称恢复了原作参数或完整逐帧一致。

## 实现变化

- 横向位移决定半径目标；同一笔上下移动会沿坯壁连续改变接触高度，能从腹部一路收至颈部。以 1.5 px 路径间距重采样，并处理 Chrome 合并指针事件，使结果不依赖鼠标事件密度或渲染频率。
- 从 28 ms 时间常数改为 12 ms。松手保留原有收敛曲线，取消强制一步跳到目标；快速拖动立即松手也在动画帧内连续完成。撤回会中止正在收敛的笔触，恢复半径、高度、厚度与轮痕。
- 屏幕比例由抓取点的真实相机深度计算，抓取后保持不变。轮廓外 14 px 内允许拾取边缘，已抓住的笔触可以移出原轮廓。`Shift` 在接触附近抹平，不再把整件器形一并抹平。
- 轮廓改用曲率连续的三次 B 样条，避免逐段插值限幅形成小平台与高光折点。保持 256 纵向、128 周向分段；口沿增加至 16 段，修正内壁与口沿错开 4 mm 的连接。圈足补足倒角支撑点。
- 复用剖面点、顶点、法线、索引和缓存数组；预计算圆周三角函数，只有高度变化时更新 UV，解析更新包围体。保留高画质、扫描贴图分辨率和几何精度，塑形期间不上传彩绘贴图。
- 湿泥基色调整为偏灰橄榄色，降低湿润粗糙度与扫描法线强度，保留水膜反射和干湿差异。真实接触路径留下最多 0.1 mm 的细轮痕，抹平会局部削弱轮痕；接触带通过粗糙度变化反馈当前位置，不增加自发光。轮痕进入工坊存档和导出几何。

## 复现

```powershell
npm test
npm run build
node scripts/serve.mjs --port 5191
# 另一个 PowerShell 窗口：
$env:QA_PREFIX = 'sculpt-local'
node scripts/sculpt-motion-check.mjs
python scripts/analyze-sculpt-capture.py sculpt-local
# 源录像测量需要 Python 的 opencv-python 和 numpy：
python scripts/analyze-sculpt-reference.py
```

录像可设置 `$env:QA_RECORD='1'` 和 `$env:PLAYWRIGHT_BROWSERS_PATH="$PWD/.tmp/playwright"`，需要已经安装 Playwright FFmpeg。录像与不录像的性能验收分开运行。

`启动窑火.cmd` 仍然提供现有 `dist`，不会自动编译。改完代码需先构建；本轮已构建。已有标签页需要 `Ctrl+Shift+R` 强制刷新以绕过旧页面缓存，存档无需清除。页面实际加载的入口应为 `workshop-DbXPQJWh.js`。
