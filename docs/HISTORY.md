# 工艺与历史边界

场景选择清代乾隆时期景德镇民间工坊及共享窑场，依据项目方案中的首发范围。品牌上的 1743 指唐英《陶冶图说》的成书背景，不代表对一座有确定地址的 1743 年工坊进行了复原。

| 环节 | 本作处理 | 近似与省略 |
| --- | --- | --- |
| 原料 | 领取已初步处理的瓷石、高岭土配泥，再调水、淘洗揉练 | 破碎、沉降、陈腐由原料行完成，文字解释产业分工 |
| 成形 | 竹杖起轮、定中心开孔、双手调节轴对称坯壁 | 48 环网格与近似壁材体积守恒；不是有限元泥料仿真 |
| 阴干、利坯 | 阴干到半干再削壁，清足后釉坯继续干燥 | 含水率和时间压缩，没有加入强晒即干的捷径 |
| 青花 | 青料绘在坯面，透明釉下高温烧成后显青蓝 | 记录笔触、浓淡、位置；不声称模拟钴料真实化学反应 |
| 施釉 | 浸釉深度与时间决定覆盖及厚度，必须清底足 | 厚度刻度为游戏无量纲参数，不是历史配方 |
| 烧窑 | 匣钵、窑位、添柴、风道、火候与自然冷却 | 温度曲线和热功是经验玩法近似，压缩跨日等待 |
| 验器 | 欠火、过火、薄壁开裂、气隙针孔、厚釉流釉、漏釉、气氛发色偏差 | 缺陷来源可解释，外观为程序化近似；品质分数仅用于游戏 |

没有把现代电动轮、必做素烧、所有青花二次彩烧写入主线。不同朝代和瓷种需要独立工艺设计，不以换色冒充。

窑炉和建筑为适合步行与操作的合成模型，窑门、拱顶、棚架和匣钵表达共享柴窑的作业关系；具体镇窑结构与材料细部仍应由专业考古和工艺顾问复核。手部比例以米为尺度制作，动作通过鼠标接触点和约束骨骼驱动。
