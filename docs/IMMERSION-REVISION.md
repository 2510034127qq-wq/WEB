# 沉浸体验改造记录

本轮从 `bfed84d` 建立 `feat/embodied-workshop` 分支，按反馈重做具体材质、光影、人物步态和直接操作。画面是否达到用户要求的以假乱真程度需要实机评价；通过程序检查不能替代该评价。

## 免费资产

实际通过 Fab 下载并在场景中使用两件资产，均有可下载的通用 GLB，均为 CC BY 4.0：Glowbox3D 的 Hanging Ancient Pottery Set；sixonetwo 的 Firewood Pile Scan LOWPOLY。作者、来源、授权、用途及文件哈希见 `licenses/FAB-ASSETS.md`。没有购买资源。

另使用 Poly Haven CC0 实拍 HDRI 和木、墙、砖、石地的多通道材质。文件以本地资源交付，来源和 SHA256 见 `public/assets/realism-provenance.json`。色彩图按 sRGB 解码，法线、粗糙度、遮蔽、位移按线性数据使用。木材纹理与木梁长轴对齐，地面用高度图改变实际网格，釉面反射采集庭院自身。

## 行走

速度逐渐建立和衰减；步态相位按碰撞后的实际行进距离推进。左右足交替触地，带克制的重心侧移、足跟回弹和呼吸。侧移、倒退、蹲行、持器有各自速度限制。导航也限制转身速度。脚步是合成鞋底冲击与摩擦声音，不是现场录音。

新工坊默认开启轻量步态；旧存档第一次进入此版会开启，之后尊重玩家在设置里的关闭选择。关闭晃动时仍保留惯性和平滑蹲下。蹲下调整眼高，物理胶囊暂保持原站立高度。

## 操作

- 取泥：走近原料台按 E，点击实物泥堆；1 / 2 选择制碗或瓶的意向，不替换成品几何。
- 练泥：按住泥团，来回推揉。手不移动不会积累揉练。点水碗润手。
- 拉坯：拨动轮盘后，压住泥心下拉开孔；扶壁横向收放、纵向提拉。轮有惯性和接触阻力。空格是拨轮辅助键，B 制动，Shift 拖动抹平，Ctrl+Z 撤回。
- 利坯：刀锋要落在半干器物表面，轮速足够才会削薄；离开器壁或停轮即停止。
- 绘画：直接在三维坯体落笔。砚台加青料，清水碗稀释；Shift+滚轮调整笔锋，滚轮旋看器物。
- 施釉：抓住器物向下拖入釉、向上提起。浸入深度和停留时间实际影响釉层。出釉后在底足右键来回擦拭。
- 窑前：实物柴、火折子、封窑砖、风闸作为操作对象；主动拖风闸会退出自动扶火。
- 包装：拖纸向器物折拢，过程由手势决定。
- F 托起坯板，E 放到下一工位，Esc 起身。阴干和窑火的时间压缩仍使用按住 R。

工作台默认只保留角落动作提示；无常驻工艺滑块。器物记录、导出和系统设置仍用普通界面。

## 边界

本轮仍是鼠标键盘约束动作，不提供触觉力反馈、两只独立六自由度手部输入或完整软体泥料求解。建筑属于合成工坊，免费陶罐和柴堆不构成清代景德镇考古依据。手指、衣袖、建筑构件和植物的整体真实感仍需继续按实机画面评价，不能仅因为使用扫描资产就称为照片级。

旧 `qa/playtest.json` 和 v1.0.0-rc.1 发布包只证明旧版完整流程。本轮的工位手势回归、步态录屏和构建结果单独记录，不能混用旧数据宣称新版完整通关。
