## 1080p 性能

设备为 AMD Ryzen 9 8945HX、NVIDIA GeForce RTX 5060 Laptop GPU、约 63 GiB 系统可用总内存，Windows Chrome / ANGLE D3D11。每档使用独立浏览器上下文，1920×1080、DPR 1，预热 2 秒后按相同路线行走和转动视角 12 秒，关闭录像。

| 画质 | 平均 FPS | 帧耗时中位数 | P95 | P99 | 超过 33.4 ms 的帧 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 高 | 59.89 | 16.7 ms | 16.8 ms | 16.9 ms | 0% |
| 轻 | 59.89 | 16.7 ms | 16.8 ms | 17.0 ms | 0% |

高画质路线末帧统计为 133 次绘制、约 69.9 万三角形（包含阴影和后处理的多遍渲染）；轻画质为 64 次绘制、约 35.0 万三角形。该结果说明这台设备在这条路线上的表现，不是对所有设备或满容量存档的 60 FPS 保证。完整游玩另有录像，录像开销不混入这组性能数值。

本机 HTTP 的资源就绪时间为高画质 533 ms、轻画质 263 ms，首屏传输约 8.16 MB；这是本机回环网络测试，不能当作公网或弱网加载时间。详见 `qa/performance.json`。全量资源独立保存，离线缓存不依赖公共 CDN。

## 视觉审阅

`qa/review/` 保留了最终院落、湿泥、双手、青花、蘸釉、窑火、成器和包装画面，以及 Chrome 实机录像。另保留前后对照，覆盖木料 / 手部比例、蘸釉出画、窑前构图和纹样内外壁问题。

其中标有 `replay` 的图片和最终短视频通过公开 JSON 导入重放实际游玩作品，并调整阶段以便定点审阅；它们用于视觉复查，不作为完整制瓷流程通过的证据。完整流程由 `scripts/playtest-v02.mjs` 与 `qa/playtest.json` 单独证明。原始完整游玩录像留在本地 `qa/video/`，不进入 Git；精选录像随交付包提供。

已修复：近景镜头背向工位、中心柱遮挡、指甲缩放、画笔手部穿入案台、蘸釉镜头丢失器物、袖臂断开、器身法线接缝、内外壁纹样共用贴图区域、辅助烧窑过火、多件作品重叠，以及模型导出中的自定义类克隆问题。

**视觉基准尚未经项目所有者批准。** 当前模型、材料、手部与包装动作可以直接审阅；它们仍是实时游戏资产及约束动画，不声称已经达到照片级复原或专业工艺 / 考古验收。

## 已知范围

- 单机、浏览器本地保存；没有云账户、多端自动同步或多人模式。
- 桌面键鼠优先；没有完整触屏操控，也未测弱网和移动 GPU 性能。
- 泥料、热工与缺陷是游戏模型，没有以真实窑炉和配方做物理标定。
- 工作场景是民间工坊与窑场的紧凑合成空间，具体历史器具细部可继续接受专业复核。
- 原生音效为合成声音；没有录制真实窑场环境。

Git 保留基础搭建、核心玩法、画面与离线交付、实测与发布记录等里程碑；发布标签指向候选版的最终提交。没有配置远程仓库，也没有上传或公开发布。
