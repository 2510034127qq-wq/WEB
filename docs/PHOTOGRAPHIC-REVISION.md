# 写实重制记录

本分支 `codex/photographic-workshop` 继续修改原游戏，不是新的验收版本。`v1.1.0-preview.1` 是修改前的可回退节点。以下记录不等于已达到照片级真实感。

## 已实施的资产和渲染改动

- 主要木构改为独立承重柱、檩条、椽、斜撑、柱脚；台面为分板，底部保留腿、牙板和横撑。瓦片有厚度、搭接和脊瓦；窑券按径向砌筑。
- 原始分件保存在 `art/workshop-components.blend`，合并材质后的游戏源文件为 `art/workshop.blend`。程序用于复现尺寸、构造和装配，不能凭脚本名称判断结构已经合格。
- 新增 Poly Haven 木器、编织器和陶罐原始拓扑/UV/4K PBR，来源见 `scan-provenance.json`；不是把下载的贴图套在原始方块上替代模型。
- Fab 手资产换入现有游戏骨架，保留原作者 UV、皮肤材质和指骨；修正了错误的左右镜像。持笔依据实际指节长度求接触，仍需连续姿态复核。
- `art/craft-tools.blend` 保存笔杆、笔毫、缠线、薄刃修坯刀、实心截面釉缸和折叠泥料；用于 Web 的网格按材质合并，避免每根笔毫产生独立绘制调用。
- 墙、木、砖、石、瓦、存放坯体和陶缸分别使用独立第二 UV。Cycles 128 样本计算可见天空和太阳间接反弹，再用合成器降噪。HDR 保存避免暗部量化和高亮截断；直接太阳与人物阴影仍实时计算。
- 局部反射已改为 Cycles 在八个实际工位的 HDR 采样，与静态烘焙使用同一天空、太阳和建筑。交付木构按实际区域分组，保留完整几何、材质和两套 UV，使静态器物也能选择局部反射。没有添加均匀半球补光或 Bloom。
- 主角泥坯已停止使用泥灰墙法线，改为 ambientCG Clay005 的 20cm 泥土表面；泥料使用 Clay006。已移除整器等距正弦圆环，改为记录玩家实际接触的高度、压力与轮速；抹平和利坯会减弱痕迹，旧存档不会凭空生成痕迹。烧成圈足不施加透明釉高光。
- 清水使用 1.333 IOR、厚度和透射，接触时产生衰减波纹，边缘保留弯月面；水碗不再使用绿色透明圆片。

## 当前复核结论

2026-10-24 的 r3 静帧复核指出五项主要缺陷：静态/动态明暗不一致、主角错误的墙灰法线、手指缺乏器壁接触约束、清水像漆面、庭院背景暴露直杆树和荒地边界。前四项已修改并继续验证；林地资产正在处理。复审者参与过旧版渲染，只能称作与当前实施分开的复审，不能称完全独立作者审查。

`qa/hand-r4-wheel.png` 已检查左右手修正；`qa/hand-r6-paint.png` 已检查笔杆不再悬在腕旁。静帧不能证明连续动作没有穿插，也不能替代完整生产链验收。

单元测试 17 项通过。增加轮制曲面细分后，原测试硬编码了旧剖面点数；已改为按真实内外法线查找两侧壁，继续断言独立 UV 和圆周接缝法线一致。一次开发热更新期间的交互测试因上下文重建失败，失败记录保存在 `.tmp/immersion-hmr-failure.json`，不作为游戏通过证据；后续使用冻结的生产构建验证。

尚未发布新的完成标签，也未宣称达到“以假乱真”。需继续检查全部工位的近景接触、制造痕迹、林地远景、持续操作、帧时间以及存档/模型导出。

- 打包排除未采用的候选和原始大型目录；使用中的松树贴图打包进可编辑 `.blend`。本地服务器流式发送大文件，离线缓存限制为两条下载队列。
