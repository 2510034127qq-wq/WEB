# 工作台鼠标操作（2026-10-27）

用户明确取消可见手部和手部操控。玩家仍在院落中行走，走近工作台按 E 进入；操作时解除视角锁定，使用普通鼠标光标点击、拖动器物与工位工具，Esc 离开。

## 变更

- 删除游戏手部模型加载、骨骼姿态、手指接触求解、伸手、双段手臂及皮肤更新代码；搬运与各工序均不显示玩家手或手臂。
- 删除手部独立演示入口及相关运行时测试。原始用户 FBX、贴图、可编辑 Blender 和历史记录仍保留，供版本恢复使用。
- 正式网页、离线缓存不包含新旧手部模型及绑定 JSON。旧缓存随新的 Service Worker 版本激活而清理。
- 保留鼠标射线命中器物、真实拖动塑形、练泥、绘画、浸釉和工位工具操作；接触数据服务于器物与工具，不再驱动人体。
- 工位默认箭头光标，交互工具使用系统点击指针；进入、离开均重置光标。提示改为鼠标操作，不再要求移动双手。

## 验证

- `npm test`：25 项工艺、存档等测试通过。
- `npm run build`：通过；Three.js 与物理库仍有大分包提示。
- `scripts/cursor-work-check.mjs`：18 项浏览器检查通过，运行错误 0，手部资源请求 0。真实鼠标输入检查练泥、塑形、绘画、入釉，以及八个工位的光标与视角锁定状态、离开工位和行走。结果、截图和录屏见 `qa/cursor-work-r38*`；已目视检查练泥、拉坯、绘画和浸釉截图，均无玩家手部。
- 本次验证针对取消手部与鼠标操作，不代表整个项目已经通过照片级真实感验收。
